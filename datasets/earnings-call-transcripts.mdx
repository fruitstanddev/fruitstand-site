## Data Ingestion

Data is ingested into Snowflake with best practices in mind.

<Steps>
  <Step title="Logical layers">
    Source → streamed parquet → S3 dated folder (raw snapshot) → Snowflake staging tables → transformations → curated Snowflake final tables/views.
  </Step>
  <Step title="Incremental ingestion">
    Weekly updates are pulled; downstream assets update only companies whose transcripts have changed or are new.
  </Step>
</Steps>

## Data Quality

- Explicit file log tables track S3 object lineage (location, stage, timestamp, latest flag) enabling audit and reprocessing.
- Asset checks assert presence of required fields and row deltas (extensible to freshness / volume anomaly detection).
