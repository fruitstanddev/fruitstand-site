## Schema

Transcripts are available in a flat, query-ready table — one row per speaker paragraph:

| Column | Type | Description |
| --- | --- | --- |
| `symbol` | `varchar` | Ticker of the reporting company |
| `fiscal_year` | `number` | Fiscal year of the earnings call |
| `fiscal_quarter` | `number` | Fiscal quarter of the earnings call |
| `report_date` | `date` | Date the earnings call took place |
| `speaker` | `varchar` | Name/role of the speaker for this paragraph |
| `content` | `varchar` | Verbatim paragraph text |
| `paragraph_number` | `number` | Order of the paragraph within the transcript |

```sql
select 
  symbol, 
  fiscal_year, 
  fiscal_quarter, 
  speaker, 
  content,
from earning_call_transcripts_flat
where symbol = 'AAPL'
  and fiscal_year = 2025
  and fiscal_quarter = 4
order by paragraph_number
limit 4;
```
